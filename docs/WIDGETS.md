# Designing a TV

Admin → **Screens** → a TV → **Design this TV**.

- **Add** a widget from the list on the left. Widgets marked with several uses (text, picture,
  clock...) can be added as many times as you like.
- **Move** it by dragging, **resize** it from its corner, **remove** it with ×.
- **Click** a widget to change its settings in the panel on the right.
- **Save**. The TV reloads with the new design within a few seconds.

The screen is a grid of 24 columns × 12 rows over a 1920 × 1080 picture, so one cell is about
80 × 90 pixels.

## One design for all TVs, or one each

- Tick **Use this on every TV** next to Save to give every TV this design and background.
- Or use **Copy layout from this TV** under the canvas to start from another TV's design.
- **Standard layout** puts the original design back.

## Background

On the left of the designer: pick an approved photo or video from the media library, and drag
**Darken it** until text reads well (40% is a good start). *Animated colours* is the built-in moving
background.

## Settings every widget has

| Setting | Choices |
|---|---|
| Box | Glass card, solid colour, or no box |
| Accent colour | The colour of titles and small details |
| Box colour (solid) | Used when Box is *Solid colour* |

## Widgets

| Widget | Several? | Its own settings |
|---|---|---|
| Text / announcement | Yes | Title, text, text size, line up, right to left, text colour |
| Picture | Yes | Picture (from the media library), fill or whole picture |
| Video on a loop | Yes | Video, fill or whole video. Plays without sound |
| Photo slideshow | Yes | Photo list (or every approved photo), seconds per photo, fit |
| Digital clock | Yes | 12 or 24 hours, seconds, date, English / Arabic / both |
| Countdown | Yes | Label, date and time, text when it is over |
| QR code | Yes | Link, text under it |
| Weather now | Yes | °C or °F. Uses the location in Display settings |
| Web page | Yes | Address (https://...), zoom. Some sites refuse to be shown inside another page |
| Scrolling announcements | No | Speed. Messages come from Admin → Ticker messages |
| Logo | No | Uses the logo in Display settings |
| Analogue clock and date | No | Arabic and English date |
| Prayer times | No | City and method in Display settings |
| Arabic headlines wheel | No | RSS feeds with language *Arabic* in Admin → News feeds |
| Video / slideshow | No | What plays is chosen by reception on the TV control page |
| About us / news | No | Admin → About us, or English RSS feeds |
| Flag / picture | No | Plays `media/display/flag.mp4` or shows `flag.jpg`, otherwise draws a flag |
| Contact and QR | No | Contact details and QR link in Display settings |

Pictures and videos must be **approved** in the media library before they can be picked.
